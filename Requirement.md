# Doc Vault

**Doc Vault: Agentic AI-Based Personal Document Management System**

A privacy-first personal and family document management system that combines secure document storage, OCR, AI-based classification and metadata extraction, natural-language document retrieval, expiry tracking, and controlled document sharing.

---

## 1. Technology Stack

| Component | Technology |
|---|---|
| Frontend | Flutter + Dart |
| Core Backend | Java + Spring Boot |
| AI/RAG Service | Python + FastAPI |
| Database | MongoDB |
| Cache / Queue | Redis |
| File Storage | S3-compatible Object Storage |
| OCR | Tesseract + TrOCR |
| LLM | Gemini / Groq |
| Vector Search | MongoDB Vector Search |
| Containerization | Docker + Docker Compose |
| Version Control | Git + GitHub |
