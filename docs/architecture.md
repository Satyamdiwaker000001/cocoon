# System Architecture

## Overview
This repository contains the multi-tier codebase for the **Cocoon** project.

## Architecture Components

- **Frontend (`/frontend/flutter_app`)**: Flutter mobile / web client application.
- **Backend (`/backend/springboot`)**: Spring Boot REST API server & business logic services.
- **AI Service (`/ai-service/fastapi`)**: FastAPI service for machine learning algorithms, NLP, and computer vision models.
- **Infrastructure (`/infrastructure/docker`)**: Docker files, deployment scripts, and container configs.
- **Documentation (`/docs`)**: Project architecture, API specs, UI/UX guidelines, security policies, and dev guides.
